# Hướng dẫn Communication cho App/Mobile Team

Khi xác định người dùng thuộc App/Mobile Team (iOS/Android), hãy sử dụng các nguyên tắc và template dưới đây.

## 1. Thuật ngữ (Terminology)
Giữ nguyên các từ:
- TestFlight, App Distribution (Firebase), App Center
- Crashlytics, Store Submission, Review Apple/Google
- Deep Link, Push Notification, OS Permission (Camera, Location...)
- Build version, Build number

## 2. Template Bàn giao QC (Ready for QC)

**[ Feature Name / Phase ] - READY FOR QC 🚀**

@QC-Team Bản build mới chứa tính năng **[tên tính năng]** đã có trên **[TestFlight / App Distribution]**.

**Thông tin Build:**
* Platform: [iOS / Android]
* Version: [VD: v1.2.0 (45)]

**Scope chính:**
* [Tính năng mới / Màn hình mới]

**Lưu ý khi test:**
* [Cần cấp quyền OS (Location, Camera...)]
* [Test kỹ trên các dòng máy/OS version cụ thể nếu cần]
* [Regression area]

**Tài liệu liên quan:**
* Figma: [Link]
* Link tải/QR Code: [Link TestFlight/App Center]

**CC:** @Backend-Team @PM

## 3. Cập nhật Store Submission
**[ Feature Name ] - STORE SUBMITTED 📢**
App đã được submit lên [App Store / Google Play] để review.
**Version:** [v1.2.0]
Dự kiến sẽ có kết quả trong 1-2 ngày tới. Sẽ update khi app Live.
